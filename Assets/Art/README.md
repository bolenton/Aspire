# Companion Art

Drop the companion portraits here as square PNGs (transparent background
preferred, ~1024×1024), named exactly:

- `ember.png` — the fox
- `petal.png` — the butterfly
- `clover.png` — the bunny

The app picks them up automatically (CompanionAvatarView): they appear on
the choosing screen and beside the narration in-game, breathing while idle
and bouncing word-by-word as their lines are spoken. Until a file exists,
the emoji placeholder is shown.

**Before committing art: add a row to ASSETS.md** with the source and
license (including which generator was used, if AI-generated).
